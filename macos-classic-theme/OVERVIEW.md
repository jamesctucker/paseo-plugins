# macOS Classic

macOS Classic brings the look of Apple's classic native macOS apps to Paseo, with a light and a dark theme. Both pair a clean white (or near-black) content background with the familiar macOS chrome grays and system blue accent.

Pick either theme in Settings, under Appearance. The themes follow the palette of the macOS Classic theme for Zed by huacnlee, so Paseo sits comfortably next to other apps styled the same way.
